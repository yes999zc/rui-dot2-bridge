**回答这 5 个问题（按 1–5 打分或直接说）：**

1. `00` 和 `02` 比，**响度提升明显吗**？（明显 / 一般 / 没区别）
2. `02` 有没有**失真/破音/发闷**？特别留意低频（原厂 EQ 在 150 Hz 有 +39.9 dB）。
3. `02` 的**人声清晰度**比 `00` 差多少？（不影响 / 略差 / 明显变糊）
4. 播 `01`（只 EQ）时，**是不是明显爆音**？——这是反例，用来确认限幅必须存在。
5. 总体：**愿意用 02 作为正式方案吗**？（愿意 / 要再调 / 不要）
